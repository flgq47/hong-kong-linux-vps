## 到手后的第一小时：验机清单

不管买哪家的香港 VPS，开通后先花一小时验货，问题在退款窗口内发现才有得退。

1. `ping` / `mtr` / `traceroute` 测到你常用网络的延迟和晚高峰丢包——这一步对香港机器尤其重要，直接验证线路成色
2. `fio` 测磁盘读写，`stress-ng` 跑 10–20 分钟看 CPU 是否掉频
3. `iperf3` 测带宽，顺便实测到大陆的速率（绿云香港这条会卡在 10Mbps 附近，属正常）
4. 检查分配到的 IP 信誉，进黑名单就开工单换
5. 确认没问题后，立刻配好备份、Fail2ban，改掉 SSH 默认端口
